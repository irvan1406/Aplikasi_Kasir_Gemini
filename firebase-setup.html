Setup Firebase Warung Scan

Dapat dilakukan seluruhnya lewat browser di HP.

Setelah selesai, gunakan satu email akun toko yang sama pada semua HP. Barang, transaksi, pelanggan, piutang, dan cicilan akan tersinkron otomatis. Saat internet putus, aplikasi tetap memakai data lokal.

1. Buat project Firebase

  1. Buka console.firebase.google.com lalu masuk dengan akun Google.
  2. Tekan Create a project / Buat project.
  3. Nama project boleh warung-scan. Google Analytics boleh dimatikan agar lebih sederhana.

2. Daftarkan aplikasi Web

  1. Di halaman Overview, tekan ikon </> Web.
  2. Isi nama aplikasi Warung Scan. Firebase Hosting tidak perlu dicentang.
  3. Tekan Register app.
  4. Salin seluruh bagian firebaseConfig yang berisi apiKey, authDomain, projectId, dan appId.
  5. Kembali ke Warung Scan → Pengaturan → Sinkronisasi Banyak HP, tempel pada kolom Konfigurasi Firebase Web, lalu tekan Simpan Konfigurasi.

3. Buat Firestore Database

  1. Firebase Console → menu Build → Firestore Database.
  2. Tekan Create database, pilih Production mode.
  3. Pilih lokasi terdekat dan lanjutkan sampai database dibuat.
  4. Buka tab Rules, hapus isinya, lalu tempel aturan di bawah dan tekan Publish.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }
    match /{document=**} {
      allow read, write: if false;
    }
  }
}

4. Aktifkan login Email/Password

  1. Firebase Console → Build → Authentication.
  2. Tekan Get started, buka tab Sign-in method.
  3. Pilih Email/Password, aktifkan pilihan pertama, lalu Save.
  4. Jika ada menu Authorized domains, tambahkan irvan1406.github.io.

5. Buat akun toko di HP pertama

  1. Buka kembali Warung Scan. Jika baru menyimpan konfigurasi, tunggu aplikasi memuat ulang.
  2. Masuk ke Pengaturan → Sinkronisasi Banyak HP.
  3. Isi email milik toko dan kata sandi minimal 6 karakter.
  4. Tekan Buat Akun Pertama hanya sekali.
  5. Tunggu sampai badge berubah menjadi Tersinkron.

6. Hubungkan HP berikutnya

  1. Pasang/buka Warung Scan di HP kedua.
  2. Tempel konfigurasi Firebase Web yang sama dan simpan.
  3. Isi email dan kata sandi akun toko yang sudah dibuat.
  4. Tekan Masuk, bukan Buat Akun Pertama.
  5. Tunggu badge Tersinkron. Data dari HP pertama akan muncul otomatis.
Penting: jangan kirim kata sandi, private key, Server Key, atau file akun layanan kepada siapa pun. Konfigurasi Firebase Web memang digunakan oleh aplikasi, tetapi keamanan data tetap bergantung pada Firestore Rules dan login akun toko.
